# Зачем Kubernetes

### В больших системах Docker'а недостаточно
Docker хорошо запускает контейнер на одном машине, но в проде всё обычно сложнее.

- Контейнер может упасть;
- Нужно несколько копий сервиса;
- Сервер может быть недоступен;
- Нужно обновлять версии;
- Нужен стабильный доступ к приложению.


### От команд к желаемому состоянию
Вместо "сделай действие 1, 2, 3" даём указание "поддерживай состояние".

Docker:
- `docker run ...`
- `docker stop ...`
- `docker rm ...`

Kubernetes:
- `хочу 3 копии`
