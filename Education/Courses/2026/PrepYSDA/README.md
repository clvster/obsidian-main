# SHAD 2027 — перезапуск с нуля, ноябрь 2026

- `master-plan.md` — общий план 2 ноября 2026 — ориентировочный май 2027, 20 занятий по 90 минут = 30 часов/неделю.
- `november-calendar.md` — содержание каждого учебного дня 2–30 ноября: коды и точные задачи для календаря; в воскресенье разбор.
- `progress-and-review.md` — шаблон отслеживания навыков и воскресной ревизии очередей.
- `calendar-preview.csv` — сводка дат, числа сессий и направлений (без текстов заданий). Не импортировать поверх существующих событий: могут появиться дубли.
- `prompt-{algebra,analysis,probability,combinatorics,algorithms}.md` — промпты для создания детальных тематических планов внутри пяти предметных чатов.

**Важно:** математика стартует с нуля, алгоритмы продолжаются с незакрытой задачи блока 2 10-го сезона Яндекс Тренировок. Понедельник–четверг: два предмета × две 90-минутные сессии на предмет (4 за день); пятница: линал и тервер по одной сессии; суббота: комбинаторика и «Вернуться» по одной сессии. Итого 20 сессий = 30 часов за неделю. В субботу — комбинаторика + «Вернуться». До 23:00, воскресенье 19:00 — разбор. Номера событий — плановая очередь, не доказательство выполнения.

Этот комплект исправляет тексты файлов. События календаря «ШАД» на 2–30 ноября ранее были обновлены; данная правка файлов не меняет Google Calendar.
