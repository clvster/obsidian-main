# Тренировки «Тоджи» — план и журнал

Теория, питание и пояснения: [[Toji_Guide]]

## Как читать и заполнять

| Обозначение | Значение |
| :-- | :-- |
| **Б** | Базовое упражнение: движение в 2+ суставах, работает много мышц, самые тяжёлые веса |
| **И** | Изолирующее упражнение: движение в 1 суставе, нагружает в основном одну мышцу |
| **Ф1 / Ф2 / Ф3** | Сколько подходов делать в этой фазе. Уже посчитано, ничего вычислять не нужно |
| **—** | В этой фазе упражнение не делается |
| **RIR** | Сколько повторов остаётся в запасе в конце подхода |
| Запись в журнале | `вес×повторы по подходам`, например `40×8,8,7`. Для подтягиваний и брусьев без веса: `ВТ×10,9,8`, с весом: `+5×8,7,7` |

Все веса — **в кг**. Тренажёры с плитками в lbs: пиши `lbs` рядом с числом.

## Расписание

**Пн** — Верх А · **Вт** — Низ А · **Ср** — отдых · **Чт** — Верх Б · **Пт** — Низ Б · **Сб/Вс** — отдых

| Неделя | С понедельника | Фаза | RIR базовых | RIR изоляции |
| :-- | :-- | :-- | :-- | :-- |
| 0 | 29.09 | Тест | 2 | 2 |
| 1 | 05.10 | Ф1 | 3 | 3 |
| 2 | 12.10 | Ф1 | 2–3 | 2–3 |
| 3 | 19.10 | Ф1 | 2 | 2 |
| 4–9 | 26.10–30.11 | Ф2 | 2 | 1 |
| 10 | 07.12 | Разгрузка | 3–4 | 3–4 |
| 11–16 | 14.12–18.01 | Ф3 | 1–2 | 1 (последний подход можно 0) |
| 17 | 25.01 | Разгрузка + замеры | 3–4 | 3–4 |

**Разгрузка:** подходы как в Ф1, вес −10 %.

## Неделя 0 (29.09–04.10): тест

Не проверять настоящий 1ПМ. Подобрать вес на **8 повторов с RIR 2**. Подтягивания и брусья: максимум чистых повторов с весом тела, один подход.

| Упражнение                 | Вес × повторы | RIR | ≈1ПМ |
| :------------------------- | :------------ | :-- | :--- |
| Жим штанги/Смита в наклоне |               |     |      |
| Подтягивания (ВТ)          |               | —   | —    |
| Брусья (ВТ)                |               | —   | —    |
| Тяга Т-грифа с упором      |               |     |      |
| Жим гантелей сидя          |               |     |      |
| Присед со штангой          | 10x8,8,8      |     |      |
| Гиперэкстензия             | 5x8,8,8       |     |      |
| Вертикальная рычажная тяга |               |     |      |
| Жим в хаммерах             |               |     |      |
| Гакк-присед                |               |     |      |
| Махи гантелями в стороны   |               |     |      |
| Сгибания ног сидя          | 35x8,8,8      |     |      |
| Шраги с гантелями          | 10x12,12,12   |     |      |
| Подъёмы ног в висе         | ВТx8,8,8      |     |      |
| Молотковые сгибания        | 8x8,8,8       |     |      |

≈1ПМ = вес × (1 + (повторы + RIR) / 30)
