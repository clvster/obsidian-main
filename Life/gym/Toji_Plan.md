## 2. Цель: что такое «физика Тоджи»

Фанатская оценка: Тоджи ~188 см и ~84 кг, то есть почти твой рост. При ~10–12 % жира это сухая масса ~74–76 кг, FFMI ~21–22. Сейчас у тебя ~17. Разница ~15 кг сухой массы: это **2,5–4 года** последовательной работы, а не один сезон.

## 5. Неделя 0 (29.09–04.10): тест + пищевой дневник

После 4 месяцев паузы **не проверяй настоящий 1ПМ** в приседе, жимах и взятии на грудь: риск травмы и сильная крепатура без пользы. Вместо этого:

1. Разминка: 5 мин кардио, потом гриф ×10, ~50 % ×6, ~75 % ×3.
2. Подбираешь вес, с которым делаешь **8 повторов и мог бы ещё 2** (RIR 2). Записываешь.
3. Подтягивания и брусья: максимум чистых повторов с весом тела, один подход.
4. Если нужен ориентир 1ПМ, считай по формуле Эпли: `1ПМ ≈ вес × (1 + повторы / 30)`.

## 9. Питание

### Калории
| Шаг | Что делать |
| :-- | :-- |
| 1. Оценка | BMR 1662 × ~1,5–1,6 → поддержка ≈ **2500–2700 ккал** |
| 2. Проверка | 2 недели дневника: если вес стоит, средние калории = твоя поддержка |
| 3. Профицит | Поддержка + 10–20 % → стартовая цель **~2900–3100 ккал** |
| 4. Темп | +0,25–0,5 % веса в неделю = **+0,2–0,35 кг/нед** (≈1–1,5 кг в месяц) |

Точная поддержка по дневнику: `поддержка ≈ средние ккал − (изменение веса за неделю, кг × 1100)`.

| Среднее изменение веса за 2 недели | Действие |
| :-- | :-- |
| < +0,1 кг/нед | +200 ккал |
| +0,2–0,35 кг/нед | Ничего не менять ✅ |
| > +0,5 кг/нед | −150–200 ккал |
| Талия растёт быстрее плеч | −100–150 ккал |

## 10. Кардио и атлетичность
- 8–10 тыс. шагов в день.
- Опционально 1× в выходные: 6–8 спринтов по 30–40 м или 20 мин лёгкого кардио.
- Больше не нужно: на наборе лишнее кардио съедает профицит.

## 11. Контроль прогресса

| Что | Как часто | Как |
| :-- | :-- | :-- |
| Вес | Каждое утро | Натощак после туалета → **среднее за неделю** |
| Часы (BIA) | 1×/нед | Утро, натощак, одна поза; смотреть тренд за месяц |
| Обхваты | 1× в 2 нед | Плечи, грудь, талия (по пупку), бицепс, шея, бедро |
| Фото | 1×/мес | Одинаковый свет, спереди/сбоку/сзади, расслабленно и в напряжении |
| Веса | Каждую тренировку | Таблицы выше, только **кг** |

**Индекс V-силуэта:** обхват плеч / обхват талии. Ориентир «аниме-пропорций» ≈ 1,6. Запиши стартовое значение на неделе 0.
