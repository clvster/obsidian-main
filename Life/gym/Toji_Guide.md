# Гайд «Тоджи»: теория, питание, контроль

План и журнал: [[Toji_Workouts]]

## 1. Словарь

| Термин | Что значит |
| :-- | :-- |
| **1ПМ** | Одноповторный максимум: самый большой вес, который поднимаешь ровно 1 раз с нормальной техникой. Оценка без теста (формула Эпли): `вес × (1 + повторы / 30)` |
| **RIR** | Reps In Reserve, повторы в запасе. RIR 0 — отказ, RIR 2 — мог бы сделать ещё 2 повтора |
| **Базовое (Б)** | Многосуставное упражнение: движение идёт в 2+ суставах, работает много мышц, веса самые большие. Примеры: жимы, подтягивания, тяги, присед, выпады, брусья |
| **Изолирующее (И)** | Односуставное: движение в 1 суставе, нагружает в основном одну мышцу. Примеры: махи, сгибания рук, разгибания рук, сгибания ног, подъёмы на носки, шраги |
| **Двойная прогрессия** | Сначала растут повторы до верхней границы диапазона во всех подходах, затем растёт вес и повторы снова с нижней границы |
| **Суперсет** | Два упражнения подряд без отдыха между ними, отдых после пары |
| **Разгрузка** | Неделя с уменьшенным объёмом и весом для восстановления |
| **Фаза** | Блок из нескольких недель с одной задачей и одинаковыми правилами по подходам и RIR |

### Как самому определить Б или И
Посмотри, какие суставы сгибаются и разгибаются во время повтора:
- **Жим лёжа:** двигаются плечо и локоть → 2 сустава → **Б**.
- **Махи в стороны:** двигается только плечо, локоть зафиксирован → 1 сустав → **И**.
- **Присед:** двигаются бедро, колено и голеностоп → **Б**.
- **Сгибания ног:** двигается только колено → **И**.

Пограничные случаи в плане:
- **Гиперэкстензия:** движение в основном в тазобедренном суставе → считается как **И**.
- **Шраги:** поднимаются лопатки, суставы рук не работают → **И**.
- **Подъёмы ног в висе:** работает тазобедренный сустав → **И**.
- **Прогулка фермера:** удержание, а не движение → по объёму считается как **И**.

## 3. Цель: физика Тоджи

Фанатская оценка: ~188 см и ~84 кг. При 10–12 % жира это ~74–76 кг сухой массы, FFMI ~21–22. От текущих ~60 кг это ~15 кг сухой массы, **2,5–4 года**.

## 5. Принципы

| Параметр | Значение | Почему |
| :-- | :-- | :-- |
| Частота | Каждая мышца 2×/нед | Upper/Lower даёт это автоматически |
| Объём | 8–10 подходов на мышцу → 12–16 для приоритетных | Рост идёт с объёмом, но отдача постепенно падает |
| RIR | 1–3 | Ближе к отказу — больше гипертрофии, но после RIR ~2 выигрыш мал |
| Отдых | Б: 2–3 мин, И: 60–90 с | |
| Амплитуда | Полная, с акцентом на растяжение | Разгибания над головой растят трицепс сильнее, чем вниз |
| Мышечная память | Возврат быстрее первого набора | Первые месяцы прогресс быстрый — не форсируй веса |

### Двойная прогрессия
Когда во **всех** подходах сделал верх диапазона с нужным RIR — в следующую тренировку добавь вес.

| Упражнение | Шаг |
| :-- | :-- |
| Присед, румынская тяга | +5 кг |
| Жимы и тяги штанги | +2,5 кг |
| Гантели | +1–2 кг |
| Тренажёры и блоки | Следующая плитка |
| Подтягивания, брусья | До 10–12 повторов с весом тела, дальше +2,5 кг на пояс |

## 6. Фазы — зачем каждая

| Фаза | Недели | Правило подходов | Задача |
| :-- | :-- | :-- | :-- |
| 0. Тест | 29.09–04.10 | Подбор веса на 8 повторов с RIR 2 | Стартовые веса, пищевой дневник |
| 1. Возвращение | 1–3 | **Б:** на 1 подход меньше, чем в Ф2. **И:** ровно 2 подхода | Техника и связки, без сильной крепатуры |
| 2. Накопление | 4–9 | Полный объём | Прогрессия весов |
| Разгрузка | 10 | Как Ф1, вес −10 % | Восстановление |
| 3. V-силуэт | 11–16 | +1 подход на дельты, спину, руки, трапеции; шея; подтягивания и брусья с весом | Специализация |
| Разгрузка | 17 | Как Ф1, вес −10 % | Замеры, пересчёт калорий, новый блок |

⚠️ **Январская сессия:** если сон проседает — по 2 подхода на упражнение с тем же весом.

**Шея (Ф3):** блин 2,5–5 кг на полотенце, медленно, без рывков и боли.

**Время тренировки:** ~60–75 мин в Ф2, до ~85 мин в Ф3. Не успеваешь — режь изоляцию на 1 подход, базовые не трогай.

## 8. Питание

### Калории
| Шаг | Действие |
| :-- | :-- |
| Оценка | BMR 1662 × 1,5–1,6 → поддержка ≈ **2500–2700 ккал** |
| Проверка | 2 недели дневника; если вес стоит — средние калории = поддержка |
| Профицит | +10–20 % → старт **~2900–3100 ккал** |
| Темп | +0,2–0,35 кг/нед (≈1–1,5 кг/мес) |

Точнее: `поддержка ≈ средние ккал − (изменение веса за неделю в кг × 1100)`

| Среднее за 2 недели | Действие |
| :-- | :-- |
| < +0,1 кг/нед | +200 ккал |
| +0,2–0,35 кг/нед | Ничего не менять ✅ |
| > +0,5 кг/нед | −150–200 ккал |
| Талия растёт быстрее плеч | −100–150 ккал |

### Макро (~70 кг)
| | Норма | Граммы |
| :-- | :-- | :-- |
| Белок | 1,6–2,2 г/кг; 0,4–0,55 г/кг за приём | **130–150 г**, 4 приёма по 30–40 г |
| Жиры | 0,5–1,5 г/кг | 70–90 г |
| Углеводы | Остаток | ~380–450 г |

### Пример дня (~2900–3000 ккал, ~150 г белка)
| Приём | Еда |
| :-- | :-- |
| Завтрак | Овсянка 100 г на молоке 300 мл + банан + 2 яйца |
| Обед | Гречка/рис 100 г сухой + курица 150 г + овощи + 10 г масла |
| Перекус | Творог 5 % 150 г + орехи 30 г + 2 куска хлеба |

## 9. Кардио
- 8–10 тыс. шагов в день.
- Опционально 1× в выходные: 6–8 спринтов по 30–40 м или 20 мин лёгкого кардио.
- Больше не нужно: на наборе лишнее кардио съедает профицит.

## 10. Контроль прогресса

| Что | Частота | Как |
| :-- | :-- | :-- |
| Вес | Каждое утро | Натощак после туалета → среднее за неделю |

| Обхваты | 1× в 2 нед | Плечи, грудь, талия (по пупку), бицепс, шея, бедро |
| Фото | 1×/мес | Один свет, спереди/сбоку/сзади |
